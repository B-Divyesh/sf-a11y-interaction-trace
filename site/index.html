Capture boundaries

Record only when you choose.

Recording starts when you select Start. The toolbar badge and recorder bar show when capture is active.

01

Typed words stay private

Printable keys become “Character.” Sensitive field values do not enter the trace.

02

Screenshots are optional

Screenshots start off. When enabled, capture uses the visible tested tab.

03

Open the trace file offline

The exported file includes timing, focus, role, name, state, and scope notes.

Keep the trace on your machine.

  • The extension stores traces in browser extension storage.
  • The extension has no account, analytics, tracker, or upload service.
  • Exported trace files open without a network connection.
  • Nearby control snapshots are selected DOM details, not an operating-system accessibility tree.

Install version 1 manually

Install the extension ZIP.

Download and unzip the extension. Open your browser’s Extensions page and enable Developer mode.

Choose “Load unpacked,” select the extracted folder, then pin the moss-path icon.
